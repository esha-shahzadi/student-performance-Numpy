# Student Performance Analysis using NumPy

This is a beginner-friendly Python project that uses NumPy to analyze student marks.

## Features

* Displays the complete marks table
* Shows the first student's marks
* Shows the first two students' marks
* Finds the highest mark
* Finds the lowest mark
* Calculates the average mark
* Displays Pass/Fail results
* Sorts all marks

## Technologies Used

* Python
* NumPy

## Project File

`Project.Numpy.py`

## Purpose

This project was created to practice basic NumPy concepts such as arrays, indexing, slicing, mathematical functions, conditional operations, and sorting.
